# Hamilton 项目约定

## 中英文同步（用户于 2026-09-08 明确要求）

- 所有新增或修改的玩家可见文字，必须在同一改动中完成中文和英文，包括剧情、选项、角色说明、玩法说明、动态反馈、结局，以及未来美术素材中的文字。
- 使用 `src/i18n/text.ts` 的 `bi(中文, English)` 配对维护。剧情字段使用必填 `BiText`，不接受只填一种语言或空白占位翻译。
- 动态文字用 `f(bi('中文 {0}', 'English {0}'), value)`；中英文使用相同参数。中性分隔符拼接用 `cat`，不能把双语对象直接插入普通模板字符串。
- DOM 显示用 `setText` / `setLabel` 或现有 `element` / `el`，不要绕过语言更新机制。三维舞台文字沿用双语字幕或现有成对文字渲染方案；切换语言不能重开章节、重置对话或改变小游戏计时和成绩。
- 默认模式为 `dual`，中文主字幕、英文副字幕；设置支持 `zh` / `en` / `dual` 并保存偏好。检查两个单语模式及双语小窗口布局。
- 若图像中必须包含文字，应同步准备中文、英文及适合双语显示的方案；可变字幕优先由界面渲染，避免烘焙到图片中。
- 提交前运行 `npm test` 和 `npm run build`。构建包含 `check:i18n`，禁止跳过或削弱漏译与模板参数检查来通过验证。

## 执行与验证

- 复用现有状态系统、章节检查点和玩法生命周期，不为语言切换重新创建游戏。
- 尽量保留既有玩法参数。幕间普通渐入/渐出为 550 ms，标题等待 2875 ms；减少动态时为 250 ms 简化等待。
- 日常脚本使用 npm，依赖仍以 `pnpm-lock.yaml` 为准。浏览器回归说明见 README。
- 若信息缺失会影响实现决策，应简洁说明缺少什么及原因；能够独立解决的运行与验证由开发代理完成。

## 唯一游戏主流程（用户于 2026-09-09 明确要求）

- 三维游戏是唯一主流程；不再使用、维护或新增横版 2D／经典版。后续玩法、配音、设置与回归都以三维主线为准。
- 横版 2D 专用入口、实现和 Phaser 依赖已退役；旧 `?story=2d` 链接转入 `?story=3d`。共用剧情、状态、小游戏和已生成素材继续复用。

## 子域名版本管理（用户于 2026-09-10 明确要求）

- `ham.newflorencia.com` 首次线上测试版定为 `0.1.0`；后续统一以 `package.json` 为版本来源，替代旧内部版本标识。
- 每次用户要求发布更新时升级版本、更新 `CHANGELOG.md`，执行 `npm run release:pack -- --notes '具体变更'` 并保留网站及源码归档。
- 服务器版本独立保存在 `releases/<version>/site`，通过发布工具切换 `current`，禁止直接覆盖已归档版本或直接向 `current` 写入文件。
- 本地开发不自动上线；发布、校验、切换与回滚遵循 `docs/版本管理.md`，正常发布不修改其他子域名。

## 配音范围（用户于 2026-09-10 明确要求）

- George 旁白仅朗读剧情对话框内、源码说话人为 `narrator` 的台词；不朗读章节标题、选择问题、小游戏玩法／规则／操作提示、状态反馈、成绩或结局页面。
- 禁止扫描界面 DOM 自动转为旁白；生成脚本和运行时索引均排除非 `dialogue` 的 narrator 条目。以前生成的界面旁白仅归档，不再播放或续生成。
- 角色实际台词继续播放：辩论双方发言、Hamilton 军令碎片和战斗指令；不得把玩法说明改交给角色音色朗读。
- 英文配角音色按账号描述匹配：报童 Liam、市民 Chris、保皇派 Daniel；六位主要角色沿用克隆音色。准确 ID 和选择理由见 `docs/voiceover/voice-map.json`。
