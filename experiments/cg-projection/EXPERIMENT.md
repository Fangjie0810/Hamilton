## 三版意图

1. **午夜录像室 / The midnight broadcast**：木壳 CRT、曲面玻璃、微弱扫描线、录像机计时器和绿罩台灯。视频显示区域约占桌面宽度的 40%，使原片的柔软画质成为旧录像质感。
2. **阁楼放映室 / The attic screening**：悬挂亚麻幕布、机械放映机、转动胶盘与尘埃光束。适合历史回忆的叙事框架；更轻的染色和织物纹理保留原片细节。
3. **记忆档案桌 / The memory archive**：明亮纸色桌面、橄榄绿胶片检视机、私人信件和底片。俯视构图把 CG 变成可被翻阅的个人记忆。

这些是场景化视觉提案；没有增加独立的三维房间、额外音效或重新生成 CG。环境以 CSS 构造，不需要外部图像服务。视频保持原文件、原宽高比和原声音；没有通过裁剪、拉伸或重新编码掩盖画质。

## 实现边界

- `src/ui/ProjectionScene.ts`：三版装饰、选择器、语言控制与尺寸适配。单个视频元素始终位于同一个 aperture 内；只切换根节点场景属性。
- `src/ui/projection-scene.css`：完整三版环境、设备、轻量纹理和响应式布局。胶盘与尘埃随播放/暂停状态启停；减少动态时停用动画。
- `src/ui/OpeningFilm.ts`：接入实验舞台，焦点循环包括新增按钮；影片交接后把已淡出的选择区设为 inert。
- `src/ui/EntryScreen.ts`：仅在实验副本加入三版选择器。
- 未更改现有 CG 来源、49.5 秒片尾提示、57.2 秒音轨、550 / 2875 / 250 ms 转场参数、剧情和游戏状态系统。
- 所有新增可见文字使用 `bi` / `f` / `setText` / `setLabel`，语言切换不重建播放器。
