# 游戏配音接入

用户已授权自动配音及设置开关，沿用已生成的英文音频；默认开启，字幕语言独立。保留手动推进剧情。

共用播放器按说话人和完整英文原文匹配已校验的静态音频，支持顺序队列和单一播放所有权。取消、结束、错误及延迟的 play Promise 均不能恢复旧句。开关保存在 localStorage，关闭立即静音，暂停保留位置；无权限、缺文件或加载卡住时可继续游戏。

三维主线在显示台词、选定回应、章节进入、结局和玩法阶段变化时触发。UI 重绘、字幕切换不触发重复播放。未指定音色的配角保留字幕。

酒馆问题配音期间保留回应倒计时；辩论回应在踩拍后的反馈页播放；军令选中碎片可听读，听读期间保留整理时间；约克镇指令读完后开始原有节拍计时，操作可跳过读令。其余阅读面板可按原有按钮直接跳过。旁白仅朗读当前显示且存在音频的正文，不朗读所有候选按钮或 HUD。

标题页和三维暂停页共用英文配音开关。重开、离开、销毁、失焦及页面隐藏纳入现有生命周期；幕间时间、评分和状态系统不变。

验证：播放器竞态与容错单元测试、源台词及动态音频覆盖检查、真实浏览器播放/暂停/开关/重开/语言切换及计时测试，npm test 和 npm run build。

用户随后明确三维为唯一主流程：移除横版 2D 入口、专用实现与 Phaser 依赖，旧链接转入三维主线。
