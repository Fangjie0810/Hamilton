# 码头到街头的引导与酒馆辨识

用户要求读信后突出“踏上纽约街头”，并用酒馆造型和招牌明确目的地。

采用持续的黄色出口标签与地面标记，走近后的 E 交互沿用同色。相比短暂闪烁，持续提示不会因玩家阅读或转动镜头而错过；相比新增地图或强制镜头，改动直接落在已有交互上。其他主线出口复用同一视觉规则。

出口是否高亮直接取自 StoryProgress 的 exit 阶段，不新增进度或计时。最后一句信件需要玩家确认后才解锁。序幕完成时，目标和临时提示明确引导黄色入口；重开本幕后从原检查点重建普通标记。

酒馆保留砖木建筑，增加可读的双面木招牌、酒杯图案、条纹雨棚、暖窗、门灯与门边酒桶。入口模型横向对齐已有的主线/漫游交互站位，雨棚柱和酒桶纳入原寻路碰撞。招牌使用运行时 canvasText 绘制的双语纹理，中文、英文和双语随设置更新，暂停期间也能切换。纹理释放时清理语言订阅。

验证范围：npm test、npm run build（含中英检查）；浏览器实际阅读、解锁、走近交互、重开、纽约对话和进入酒馆；1440×900 与 1024×640 的三语言截图。玩法计时、幕间时长和章节检查点沿用现有系统。
