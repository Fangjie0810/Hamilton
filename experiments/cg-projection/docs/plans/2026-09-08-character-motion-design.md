# 半写实人物与移动

状态：已被用户后续选择的「像素人物 + 可自由行走三维场景」取代。当前可玩样例见 `2026-09-08-hd2d-sample.md`。本方案的 `LocomotionSystem.ts` 与四项测试留作研究代码，未接入原 Phaser 游戏；不要把此文视为下一步实施要求。

用户选择人物与动作一同升级，贴近已有背景的半写实风格。

## 方案

使用带透明通道的绘制人物图集：汉密尔顿有待机、转身、起步、收步和八帧侧向步态，其他场内人物使用同一风格的全身造型。服装、身份与已有角色立绘保持连续。保留旧 SVG 为独立历史资产，新资源放入 `public/art/actors/`。图像不烘焙文字，姓名继续通过既有中英文系统显示。

运动采用有限加速、制动和转向。步态按实际位移推进；撞到边界不原地踏步，暂停、对话与失焦不继续漂移。点击目标使用制动距离减速，抵达时准确停止并触发一次互动。名字与接触阴影固定于地面，身体动作由图集提供，不再整体正弦跳动。减少动态模式保留方向与移动，简化逐帧变化。

逐帧图集适合现有 Phaser 渲染管线，提供膝盖弯曲、脚掌接触和衣摆变化。程序骨骼可作为后续更细致动作的扩展；当前无需引入 3D 角色、骨骼编辑器或外部运行时。

## 可验证步骤

1. 生成并检查透明人物资产、帧顺序和落脚基线，保存最终提示词及来源。
2. 实现独立运动状态与起停、转向、目标制动、边界和暂停测试。
3. 接入探索、标题与尾声，统一场内人物尺度、阴影与名字；保留全部玩法与双语。
4. 实际浏览器检查左右行走、反向、停步、点击走近、暂停和减少动态；复跑完整剧情及原有输入验证。

链条：玩家输入 / 点击目标 → 速度与位置 → 实际位移驱动步态 → 地面接触与身体显示 → 停步互动。
