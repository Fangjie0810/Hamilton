# 可行走三维样例：纽约街角

用户要求每幕最终成为可自由行走的三维场景，先独立实现一个样例供测试。像素角色依据现有参考生成，环境参考所提供视频前半段。

## 本次交付边界

入口为 `?demo=3d`，原六幕游戏仍可访问。制作一个可探索的纽约街角：三维砖楼、石路、绿地与树木，水岸与小码头；像素汉密尔顿和伯尔；统一的光照、接触阴影、遮挡、轻景深和氛围。支持 WASD / 方向键、点击地面寻路、Shift 快走、滚轮缩放与右键调整观察角度，靠近伯尔按 E 对话，Esc 暂停。所有文字继续中英同步，默认双语。

## 技术决定

- Three.js + WebGL，复用 Vite / TypeScript 和本地化代码。三维样例按入口懒加载，不同时创建 Phaser 引擎。
- 场景模块提供模型与碰撞数据。角色在 XZ 平面运动，使用圆形足部碰撞；点击目标在同一地图上寻路，路径进行直线化。自由镜头有限俯仰与缩放，避免人物平面从顶部或侧面消失。
- 像素人物使用 imagegen 生成的配对风格图集。固定脚底原点，按相机相对方向选择前、后、侧面序列帧，朝左复用侧向镜像；步态由实际行走距离驱动。素材底色在纹理载入时作为色键处理，不向用户显示底色。
- 人物放大使用最近邻采样；场景纹理缩小使用 mipmap，减少远景闪烁。建筑与地面共享暖色主光、冷色环境光、雾和有限后期；人物使用受光、透明裁切平面，脚底有独立接触阴影。
- 保留独立暂停、失焦释放输入、资源失败提示、WebGL 错误提示及画质切换。样例互动不写入原游戏成绩。

## 验证

导航测试覆盖绕障碍、不可达目标、斜向不穿角、移动边界、帧间隔上限与暂停。浏览器验证资源加载、自由移动、点击走近、碰撞、镜头、NPC 双语互动、设置记忆、小窗口与原游戏入口。构建执行中英配对检查。

后续每幕通过各自的场景描述提供模型、可行走区域、NPC 和剧情入口，复用样例的渲染、导航、角色与 UI 结构。

## 已实施

- `?demo=3d` 独立懒加载；标题页与样例之间可互相进入。
- 地面 XZ 坐标、圆形足部碰撞、A* 点击寻路与路径简化、键盘加减速和滑墙。路线实际绕过酒馆，水域只开放码头通路。
- 16 帧人物原图：Hamilton 前 / 后 / 侧面各四帧步态、三个待机方向，以及 Burr 待机。原图色键在运行时转为透明，提取各帧边界并统一脚底基线。角色为 2D 像素平面，场景为真实 3D；这对应用户的像素 2.5D 方向。
- 新生成像素树叶贴图；立体树干与分布在空间中的叶片共同受光。建筑零件按材质实例绘制，减少逐零件提交。
- 同一场景深度纹理提供轻景深；遮挡射线检测到人物时，建筑上部和树冠淡化，保留基座以提示碰撞边界。
- 伯尔对话有两项选择、三处可发现地点；所有界面和对话使用 `bi()`；设置和失焦暂停清空运动及自动寻路。
- WebGL / 资源错误提供重试与原游戏返回入口。语言、画质、环境动态偏好独立保存，不写入原游戏成绩。

## 扩展约束

交付验证：38 项逻辑测试及生产构建通过；Chrome 的开发 / 生产入口完成自由行走、绕楼、遮挡、三处发现、双语互动、暂停、三种语言与画质、镜头及 1024×640 布局检查。另验证资源 / WebGL 失败恢复及设置记忆，原六幕输入回归仍通过。测量与截图见 `artifacts/3d-check.json` 和 `artifacts/3d-*.png`。

这个样例用于验收视觉、尺度、移动和镜头，不代表六幕已完成三维迁移。当前在平面地表探索，没有跳跃、坡地寻路、室内或完整 NPC 行走库。下一幕需要自己的模型布局、碰撞 / 通行区、角色资产和剧情触发点；现有辩论、军令、战役仍通过原入口运行。
