## 实际截图验收

- 已逐张查看到达、变化中、变化后、返回、对话与 390 × 740 小窗口截图。画面均来自实际三维游戏；没有用背景图替代场景。
- 评估：同一个圆盘放大后保留玩家熟悉的空间对应关系，扇区填充和数字一起变化，适合作为主要属性变化提醒。左侧占位稳定，正常探索可清楚辨识；对话中必要时缩小尺寸，使正文保持可读。
- 已保留当前预演定稿：`artifacts/compass-final.png`。完整动作：`artifacts/compass-motion.mp4`，由真实浏览器帧录制，包含移入与返回。

## 数据与交互

- 每笔状态提交保存完整前后快照；多项变化同时呈现，连续提交排队，下一笔不会覆盖前一笔的动画。
