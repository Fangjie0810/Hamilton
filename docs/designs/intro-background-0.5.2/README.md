## 设计选择

| | A · 清晰导读 | B · 时代告示 |
| --- | --- | --- |
| 口吻 | 直接告诉玩家“你是汉密尔顿” | 以十八世纪告示／小册子的口吻介绍局势与来客 |
| 视觉 | 深绿黑幕、左侧细金线、大标题、单栏留白，接续 CG 黑场 | 暖旧纸、深棕油墨、双细线、衬线大标题；桌面双栏，窄屏单栏 |
| 阅读重点 | 身份 → 冲突 → 即将参与的公共讨论 | 城中局势 → 远来青年 → 战事尚无定局 |
| 适用取舍 | 初次接触的玩家更容易进入角色，建议优先采用 | 时代感更强，第三人称与略文言的中文需要多一步代入 |

B 版借鉴当时“告居民书／致居民”的印刷文本惯例，以现代读者能顺畅理解为限；不是复刻某份真实报纸，也不冒充历史原件。未使用报刊原文、音乐剧歌词、真实刊号或精确日期。

两版保持同一事实底稿，均只显示当前主语言。双语模式属于非对话背景说明，仍以中文或英文单语显示，符合现有项目约定。预览顶部的方案、语言与打印控件属于评审界面，不是拟加入游戏的按钮。

## 为什么这样写

CG 已展示母亲、商行、风灾、资助和登船，序幕读信还会解释“文字带来求学机会”。新稿只用一两句承接身份，把篇幅留给新人缺少的背景：

1. 纽约和英国殖民统治的关系。
2. 税收、贸易、自治争执为何与战争相连。
3. 革命阵营之外，王室支持者也关心秩序与生计。
4. 汉密尔顿如何通过报纸、街头与酒馆进入这些争论。
5. 伯尔的谨慎，以及华盛顿与大陆军的基本身份。

不罗列人物名单和玩法数值，也不预告决斗、人物死亡、战争胜利或具体任命。伯尔的“律师”职业标签没有写入，因为不能把后来的职业直接套到早期场景。

## 拟定落点与节奏

现有流程是 **CG → 序幕码头读信 → 第一幕纽约**，见[现有接入记录](../../plans/2026-09-11-opening-film.md)。本稿按 **CG → 背景介绍 → 序幕码头读信 → 第一幕纽约** 设计；此次仅做这一步的视觉提案，没有实际插入。

- 背景文字整段显示，玩家自主阅读，不计时、不自动翻页，不沿用短暂幕间标题的等待时长。
- 一个“走入故事”按钮；预览仅模拟淡入序幕标题，明确标注没有启动游戏。
- 延续 550 ms 淡入思路；减少动态时预览直接显示。后续接入才处理真实媒体、暂停、焦点和章节生命周期，此次未更改这些模块。
- 390px 小窗口采用自然纵向滚动保留字号，正文、年表注和按钮均可读；正文不同时堆放两种语言。
- 所有精确年表解释作为低干扰的小注置于正文之外，B 版也不把现代编辑说明混入历史口吻的正文。

## 历史核对与叙事边界

正文是结合游戏主线的原创改写。事实依据如下，查询于 2026-09-15：

- **汉密尔顿的来处、求学与早期写作：**NPS 的 Hamilton Grange 教育材料介绍他从加勒比海前往北美求学、进入 King's College，以及早期政治小册子。不同页面对具体抵达年份／地点的简写不完全一致，因此本稿不写“1776年才抵达”，也不钉死船舶入港日期。[NPS 教育材料](https://www.nps.gov/hagr/learn/education/upload/educators-guide-elementry-school.pdf)
- **税收之外的治理冲突：**国会图书馆说明了代表权、贸易限制、军事使用、政治权利等交织的问题。本稿把税收、贸易与自治并列，避免把革命压缩成单一“税太高”。[Revolution of the Mind](https://www.loc.gov/exhibits/creating-the-united-states/revolution-of-the-mind.html)
- **冲突已走向战争，独立尚在争取：**1775 年交战及 1776 年独立动议的背景支持本稿的“1776年前后”叙事视点；不把玩家的初见写成独立成功后的回顾。[美国国家档案馆：Lee Resolution](https://www.archives.gov/milestone-documents/lee-resolution)
- **华盛顿与大陆军：**1775 年大陆会议的委任书确立其军队总司令身份。本稿不使用总统头衔。[Founders Online：Commission from the Continental Congress, 19 June 1775](https://founders.archives.gov/documents/Washington/03-01-02-0004)
- **报刊／告示文风参照：**国会图书馆的《New-York Journal》馆藏记录证明同一时期纽约的报纸印刷背景；B 版只取“公开告居民”的形式与字调，不复制真实刊头或原文。[Library of Congress 馆藏记录](https://www.loc.gov/item/sn84024352/)

城市里的保皇派论点、伯尔的谨慎，以及酒馆的叙事顺序依据本游戏 `src/data/chapters.ts`。这些人物措辞是游戏改写，不能当成当事人的历史发言。

## 文件与重建

`content.ts` 从项目的 `src/i18n/text.ts` 引入 `bi`，所有文案配对维护。`build.mjs` 校验空白／缺失翻译，并生成全文及完全独立的 HTML；浏览器预览只在内存中保存语言，不访问游戏 localStorage。

```sh
node --import tsx docs/designs/intro-background-0.5.2/build.mjs
```

预览不依赖 `EntryScreen`、`OpeningFilm`、`StoryDirector` 或任何游戏入口，也不出现在 `public` 与生产网站构建里；作为设计文档随 0.5.2 源码归档。
