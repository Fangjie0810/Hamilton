# 0.5.2 本地版本 · 图示教学、人物对齐与背景设计

2026-09-15。完成本次两项游戏修改，并另行制作背景介绍设计稿。**0.5.2 为本地归档，未上传或切换线上。**

## 游戏修改

### 属性教学附带对应 UI

各项教学标题下、解释文字上方加入正式战役徽章 SVG，直接复用 `CampaignCompass`。当前讲解部位保留真实数值与填充并突出显示，其余部位降为 20% 透明度，帮助玩家认出它在左侧 HUD 上的位置。伯尔的首次教学同时突出红色竞争与蓝色尊重；单项回看突出所选区域。

图示只读，不获得键盘焦点，不模拟奖励或修改状态。序幕及军营前信任锁定的规则、五条简短解释、首次弹出时机、语言切换、设置暂停、章节重开和新局重置沿用原有行为。

### 拉法耶特说话帧对齐

定位为原图各格头部／躯干原点不同。通过 `mainPixelArt.ts` 的逐帧 `frameOffsets` 校正，并由正式对话提帧入口和检查页传入已有共享管线。原图、口型节奏、态度语义、跨格指尖与24px overscan保持，未重新生成或裁掉手势。

实际 360×450 输出中，普通开口的头部横移从19px降至0；重音头发从12px降至0，眼部最多1px；身体剩余偏差最多1px。其余态度头部也保持对齐，原有低头、眼神和手势差异保留。

## 背景介绍：仅独立设计

提供两版原创中英文内容和视觉设计：

- **A · 清晰导读**：深绿黑幕、细金线与直接的第二人称，介绍汉密尔顿、殖民地冲突、城市分歧及即将参与的公共讨论。建议新玩家优先采用。
- **B · 时代告示**：旧纸、铅字、双细线与十八世纪告居民文风；正文之外明确玩家扮演汉密尔顿，不冒充历史原件。

拟定衔接为 CG → 背景介绍 → 原有序幕读信 → 第一幕。年表注明确早年赴纽约求学与1776—1777年的革命经历被并置，不再复述完整童年／风灾 CG。没有接入游戏入口、CG、章节、音频或生产资源目录。

[交互预览](designs/intro-background-0.5.2/preview.html) · [两版完整中英文](designs/intro-background-0.5.2/copy.md) · [设计与历史来源](designs/intro-background-0.5.2/README.md)

预览是可直接双击的独立 HTML，所有内容从 `bi` 配对源文案生成；语言只在内存中切换，不读写游戏偏好。正文按主语言显示，窄屏自然滚动，玩家自行继续。
