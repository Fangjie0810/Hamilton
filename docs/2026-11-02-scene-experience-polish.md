# 场景精细化与移动稳定性 · 2026-11-02

本轮根据首版验收反馈更新 `?experience=3d`。仍是本地 0.5.2 项目内的体验入口，没有发布或切换线上版本。

## 本轮修改

| 问题／要求 | 处理 |
| --- | --- |
| 移动、转向、遮挡时墙面闪烁 | 移除相邻房间重复建模的共墙；体验页采用实体裁切平面替代屏幕颗粒遮罩，阴影同步裁切；进出房间与镜头临界角加入滞回，短时离开遮挡射线不立即恢复墙面 |
| 行走时收藏品框跳动 | 每次渲染后用同一帧相机矩阵投影，改用固定宽度与 transform 定位；显现／消失距离分别为 5.5／6.1，减少边界反复切换；实际拾取距离仍为 1.65 |
| 去掉舞会二层楼梯与粗糙 NPC | 删除两侧楼梯几何及碰撞，删除八个几何宾客；既有像素角色保留；上方回廊仍作装饰布景 |
| 精细化资产 | 十二件收藏品重新建模；家具加入倒角、榫接式框架、车制桌腿、椅背栏杆；货架加入瓶体、标签与木构支撑；箱桶加入板条、金属箍和铆钉；窗框补充窗台和分格，砖木纹理提高分辨率 |
| 纽约街头货架／货摊 | 增加分格货盘、带果柄的货物、条纹雨棚、下层货袋与支撑结构 |
| 酒吧老板桌过高 | 吧台台面由约 1.52 降至 1.06 世界单位，改为有嵌板与黄铜脚踏的柜台；顶针高度同步调整至 1.07，站位与收藏 ID 保持 |
| 舞会地板 | 独立木板构成的人字拼花，细缝、多种木色、圆形金属镶边和中心纹样；重复部件实例化 |
| 缩放百分比条 | 新增可拖动滑条与数字，与滚轮、全景和重置联动；100% = 相机半径 27，越大越近；现有半径 12–76 对应约 225%–35.53%，界面四舍五入显示 225%–36% |

当前缩放范围是保留原有相机范围的临时边界，等待后续上下限设定。映射定义集中于 `src/sceneExperience/viewState.ts`，不把 100% 解释为浏览器页面缩放。

## 收藏品细节

- 账簿：皮面书脊、纸页层、金属包角与书签。
- 封印／家书／名单：折页、抽象墨迹、封蜡、压印及装饰边框；不在模型中烘焙需翻译的正文。
- 剪刀：刃口、指环、转轴螺钉；货签：真实穿孔与绳结。
- 缎带：弯曲带面与结；顶针：旋转成形的壳体、边圈和凹点。
- 羽笔：羽片、羽枝、中轴和墨瓶；折扇：褶面、扇骨、花饰与流苏。
- 坠盒：打开的盒盖、内衬与链环；衣扣：真实孔洞和交叉缝线。

物品近景隐藏拾取光环，按物件包围范围调整镜头，细小物件也能看清。原有十二个稳定 ID、双语附文、收藏存储和剧情标签不变。

## 验证

- `npm test`：211 项通过；`npm run build`：通过（含 95 个文件的双语覆盖与 TypeScript 检查）。
- 自动测试继续用实际 Walker 和碰撞图走通所有地点、门洞与收藏品站位，补充共墙复用、进出门／镜头边界滞回、裁切保持与阴影设置、缩放往返映射、取消楼梯碰撞、吧台物品高度及货物／封蜡比例检查。
- 浏览器实际走入舞会西侧会客室、酒馆储酒间，世界版本未变化；移动与转向后检查了墙面和标签。连续裁切代替颗粒遮罩，避免了原实现的屏幕噪点闪动；尚未做多显卡平台的长期图像差分测试。
- 检查了折扇近景，三场景模型导出；缩放 36%、150%、225%、重置 100%，四种语言切换保留位置与缩放。390×844 检查了新增缩放条与页面宽度，无横向溢出；最终恢复默认窗口大小。
- 浏览器控制台未见运行错误。未发布帧率基准，不将主观顺畅程度写成性能数字。
- 导出 GLB 已检查容器头、字节长度、JSON 块、十二个收藏品节点和 SHA-256；导出是静态资产，不包含运行时遮挡、行走、界面和像素角色逻辑。

技术依据：Three.js 的世界空间裁切与阴影裁切使用 [Material clippingPlanes / clipShadows](https://threejs.org/docs/pages/Material.html)；倒角几何使用 [RoundedBoxGeometry](https://threejs.org/docs/pages/RoundedBoxGeometry.html)。

实现链条：共墙几何 → 带滞回的房间／遮挡判断 → 实体与阴影同步裁切 → 同帧投影收藏品标记；缩放条与滚轮 → 同一相机半径 → 百分比读数。
