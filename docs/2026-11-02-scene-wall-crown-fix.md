# 高墙柱头闪烁修复 · 2026-11-02

用户在 140% 视距下补充酒馆高墙截图，标出木柱与墙板顶面的黑白碎边。上一轮仅修复裁切后的低墙，没有覆盖未裁切高墙的共面顶面。

## 原因与修改

高墙墙板与竖向木柱原本都结束在同一高度；柱顶与墙板顶面实际重叠，镜头移动会让两种颜色争夺同一深度。转角处的垂直墙段也存在同高顶面交叠。

三个场景的共用建筑模块现使用 0.20 高、0.56 厚的连续顶梁。墙板与柱头终止在顶梁下，墙顶只保留一个可见表面；顶梁转角相接，门洞上方也采用同样结构。顶梁参与原有上半墙遮挡，其窄顶面不接收阴影以避免细边自阴影噪声；其余墙面及场景阴影保持原设置。

本次未更改 100%–140% 视距、低墙封口、导航、收藏品存储或主线流程；未部署线上版本。

## 验证

- 新增真实模型的向下射线回归：逐场景检查每段高墙中央柱头、两端及外角，要求最高可见面只有一个深度表面。原模型可复现两个重叠面，修改后三场景全部通过。
- npm test：213 项通过；npm run build：通过，含 TypeScript 与 95 文件的中英配对检查。
- 浏览器重走同一路径，140% 下相近站位对比（修改前 15.06,3.83；修改后 15.07,3.83），再沿右墙前进两段并改变相机角度；原柱头黑白碎边不再出现。另检查 100% 视距与三场景切换，无浏览器错误日志。
- 重新导出三个静态 GLB，校验文件结构、顶梁、低墙顶盖及每场四个收藏品节点。
