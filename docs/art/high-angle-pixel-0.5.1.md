# 高俯视 Q 版美术 · 0.5.1

使用内置 image_gen 生成。现有 Q 版图集用于人物身份、服装与像素风格参考，重新绘制约 55° 俯视，保留 9 名角色、八向映射、Hamilton 行走和街头争论动作，共 86 个原始格。

正式原件位于 `public/art/actors/high-angle-v1/`，游戏内沿用现有色键与图集规范化流程生成透明画布，不覆盖旧原件。首轮输出的棋盘格已通过 image_gen 编辑为统一洋红色幕；首轮历史图保留在生成缓存。

## 运行时

镜头俯角 >= 0.815 rad（可调范围最高 30%）时切换，人物绘制面随镜头俯角朝向玩家，避免二次挤压。高俯视体高按原 75% 规范化，脚底维持统一 120 px 线。低俯角沿用旧图。地图坐标、寻路与碰撞不变。

切图前释放旧纹理的 GPU 绑定，再替换 source，保持每位角色的帧 UV 独立。真实 WebGL 的单人切换、连续往返与整场释放结果见 [GPU 验证](verification-0.5.1/high-angle-gpu.md)。正式八向画廊与场景预览随 [0.5.1 验收](../0.5.1-validation.md) 归档。
