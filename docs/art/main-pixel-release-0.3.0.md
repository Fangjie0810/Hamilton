## 表演与去底

- 新句子通过实际媒体 `playing` 事件启动基础绘制嘴形；强调手势每句最多一次。`waiting`、暂停和减少动态不伪装成台词结束；真正结束才保持指定句后反应。
- 静音／无配音时，选中台词与回复按顺序短暂表演，完成后收口，不循环、不推进剧情。切换语言保留台词、角色、计时和小游戏状态。
- 听者保留灰黑遮罩，并依据当前台词与双方关系选姿态。保皇派听辩论保持质疑；Burr 尊重与竞争分开；Lafayette 闲聊保留笑意；军令后保留指挥姿态等待执行。
- 辩论、军令、约克镇使用原有真实成绩和命令成败选反应；不新增旁白或改变计时、分数、阈值与玩法参数。
- `portraitPixels.ts` 保留连续 alpha，并用可靠前景颜色约束低 alpha 下的色键解混，避免绿色去底放大噪声后产生品红。保护深色轮廓、酒红衣料与肤色；发卷封闭小缝也纳入检测。
- 全图集使用共同缩放和定位，清除邻格独立碎片。Hamilton、Lafayette 与 Eliza 的少量越界手指／书角通过源像素扩展提取保全；未使用的空格不参与定位。

当前为 18 张基础开口帧与独立闭口态度图，未为每个态度重复制作全套嘴形，不是逐音素唇形同步。Eliza 不显示口型；其记录动作与女声 Sarah 的既定旁白范围保持一致。
