# 低墙裁切修复与视距范围 · 2026-11-02

用户反馈酒馆前方两段裁切低墙在行走时仍闪烁，并确认百分比范围为 100%–140%。本次仅更新本地三场景体验，未发布线上版本。

## 修改

- 三个场景共用建筑模块改为独立实心低墙与连续木质顶盖。上半墙板、柱条及门框从顶盖高度 0.68 开始；遮挡裁切降到 0.62 后，完整移除上半墙，不留下开口截面或突出的柱条。
- 顶盖转角采用相接几何，消除同平面重叠。窄顶盖关闭接收阴影，避免细边自阴影噪声；其余墙面阴影保留。裁切不再使用局部 MSAA 透明覆盖。
- 滑条、滚轮和重置统一限制于 100%–140%，默认 100%。俯视按钮更名为「俯视视角 / Overhead view」，保留当前缩放并跟随角色，仅切换俯角。
- 未修改收藏品 ID、存储格式、收藏进度、门洞或导航碰撞。

## 验证

- `npm test`：212 项通过。新增几何回归检查覆盖三场景：所有待裁切墙体最低点在顶盖之上；顶盖独立于遮挡分组；顶盖之间无同平面面积重叠。缩放检查覆盖上下限及无效输入。
- `npm run build`：通过，含 TypeScript 与 95 个文件的中英配对检查。
- 本地浏览器：酒馆 100% 与 140% 行走、转向后的画面中，原前墙的细柱残边与亮截线不再出现；滚轮越界后仍为端点值；140% 切换俯视仍为 140%；四种语言切换正常。三个场景切换及导出正常，浏览器无错误日志。
- 重新导出三个静态 GLB，校验文件头、完整长度、墙顶盖及每场四个收藏品节点。浏览器观察针对本机验收视角，不替代所有设备的长时间渲染测试。
