# 场景精细化与移动稳定性 Implementation Plan

**Goal:** 修复移动／转向时墙面和收藏品框闪动，细化三场景资产，移除舞会楼梯与几何 NPC，提供缩放百分比条。

**Architecture:** 只修改 `experience=3d` 验收入口。通过共享隔墙消除重复表面，用带滞回的实体裁切替换屏幕颗粒遮罩；逐帧投影收藏品标记；细化资产保持原导航与收藏 ID。缩放统一以相机距离 27 为 100%，保持当前半径 12–76 的临时边界。

**Tech Stack:** 现有 Three.js、TypeScript、Vite；复用素材与状态，不新增依赖。

1. `SceneryKit.ts`、新 `StableCutaway.ts`：共墙单份建模、门口与镜头阈值滞回、连续裁切高度；验证进出门与转向。
2. `Experience.ts`、新 `viewState.ts`、CSS：标记逐帧投影、显示距离滞回、固定宽度与变换定位；百分比条与滚轮／重置／全景联动。
3. 新细节资产构建模块及 `SceneryKit.ts`、`Worlds.ts`：倒角家具、货摊与货物、低吧台、拼花舞池、精细十二件收藏品；移除舞会楼梯及几何宾客。
4. 测试碰撞可达性、遮挡边界稳定性、缩放映射、收藏状态与资产语义；实际浏览器检查三场景行走、转向、遮挡、双语与窄屏。
5. `npm test`、`npm run build`；更新截图、GLB 导出与验收文档，保持本地版本不发布。
