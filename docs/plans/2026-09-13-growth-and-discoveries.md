### 规则边界

- 辩论保护仅在已选择 ATTACK 后出现 MISS 时触发，包括该节拍超时；选项超时没有回应、不属于反击，不消耗保护。一次活动最多一次。触发反馈明确写明「锐气帮助你稳住场面；本次节拍仍记为失误」。
- 不改 PERFECT ±100 ms／GOOD ±250 ms，不延长辩论 2.5 秒选择、不改酒馆 10 秒选择，不减少约克镇 12 道命令。
- 保护仅取消上述反噬；不凭空增加支持、不削弱对手、不恢复连击。结算显示已获得／已使用的帮助。
- 军令提示：在当前轮选择一个片段，点击「查阅范例」，显示其正确类别；未选择片段时按钮不可用，提示不自动移动片段。全场一次，不暂停或增加 150 秒操作时间。
- 部署核对：选择一支队伍，再点击「核对部署」，显示该队推荐命令；不自动下令，不增加突袭优势。全场一次，可在该队已有选择时核对。
- 原有普通玩法说明和三队职责提示继续对所有人开放，不能先删掉基础说明再作为奖励返还。
- 受提示辅助后玩家自行提交的军令／部署照现行公式评分；结算额外标注辅助已使用，不宣称为「无辅助成绩」。节拍等级始终按真实输入记录，不增加新的总分字段。
- 加成读取活动开始时的状态（包含开始前的主线选择），不在活动中途重算。小游戏获得的奖励用于后续节点，不能倒流回当前活动。
- 叙事在对话开始时取快照，因此授命台词可能先于出发选择、玩法快照后于出发选择；提示必须说明本次具体生效的来源，不把后来增加的信任说成先前授命的原因。
- 关系解锁对话均为可选，无二次属性奖励，避免「属性解锁对话、对话又免费叠同一属性」循环。两项关系都达标时两种回应都可看，每项仅一次。
- 所有主线路径可到结局，未达门槛时提供完整基础玩法；成长面板显示下一门槛，但不锁主线或宣传必须收集。

## 3. 教程和反馈：在使用时解释

1. **第一次抵达纽约、转场完成后**：出现一张可关闭的小卡「3 项主要指标，2 项伯尔关系」。每项一句用途，说明主线选择与地图发现均可积累。目标阅读时间 15–20 秒；不另开练习关。华盛顿信任 0 标注「进入军营后积累」，关系条目随首次介绍伯尔解锁详情。
2. **完成现有买报主线**：高亮影响力，显示真实 +2 与原因；同时提示附近纸张标识是可选发现。教程不要求玩家完成该支线。
3. **第一次主线选择**：一次短提示解释 ↑／↓ 是数值变化方向，不等于对错；沿用选项预览规则，不额外显示加减点数。
4. **每项门槛首次跨过**：小提示显示新用途，例「影响力达到 25：本次辩论的初始支持将增加 5」。如果用途已经结束，改写为后续叙事用途，不能承诺过去的加成。
5. **活动准备页**：显示本场实际生效的加成及剩余次数；玩家读完再开始计时。使用后显示因果提示，结果页回顾帮助是否用过。
6. **随时回看**：HUD 的三项指标可点击／键盘聚焦，打开统一成长面板，显示五项含义、当前数值、下一用途。活动期间面板通过现有暂停机制打开，关闭恢复原计时、输入状态与配音，不另造平行暂停系统。

教程观看状态属于本轮 UI 进度，章内重开不反复弹开场介绍；属性、奖励和支线完成状态按章节检查点回滚。新一轮重新开启教程；偏好与语言继续保留。

### 展示、时效与防重规则

- 用纸张／小对话图标与主线金色标记区分；形状和文案一起区分，不能只靠颜色。保持主线导航优先。
- 道具用简单纸张几何／现成贴图，文字留在 DOM 对话中；不新增角色模型、背包、装备、任务清单、地图或战斗类型。
- 不自动把支线当成下一主目标；纸张拾起后进入已完成视觉，可查看余下描述，不能再发奖。普通闲聊继续无奖励。
- S4、S5 是准备事件，活动开始后停止发奖；如果玩家在活动后检查，显示普通后续短句，不承诺或追溯活动加成。其他事件可以在主线完成、出口开放后继续完成。
- 出口只由主线决定；可选事件进行时暂不允许离开，结束后回到原来的 explore／exit 状态。明确离开即进入下一章，不弹收集完整度确认。
- 单个事件完成时原子写入 `choices['side:<id>']` 并应用 effect；中途关闭／重开不视为完成，不发一半奖励。
- 彩蛋用 `side:letter-name` 与 `side:letter-name-echo` 两个标记；关系反馈使用 `reaction:<id>`。复用现有 choices 字典和检查点，不增加与之不一致的存档。
- 条件回声与属性变体采用「主段落 + 有条件的短句」组合，限制每次开场最多两条回声，避免每个条件展开成整套替换台词。
- 实际台词中英同改；角色配音按现有声音映射。新增 UI 规则／奖励说明不进入 narrator 配音。新语音需在交付清单中列出，缺失时文字可游玩，但不得声称全量配音已完成。

## 6. 验收标准与范围控制

- 新玩家到纽约能看懂共有 5 项成长／关系指标，区分活动成绩，并能在面板查到每项的实际用途。
- 3 项主指标各有叙事用途与可验证的玩法用途；伯尔的 2 项关系都在结局之前出现可见分歧。
- 每个支线最多一次属性奖励，彩蛋后续回声不重复加点；完整游玩无无限刷取或重开叠加。
- 不做支线也有机会跨过门槛，且所有路线完整可玩；支线可以帮助临界数值跨档，却不能替代玩家完成全部小游戏。
- 全探索新增时长目标 3–5 分钟；超出目标先缩短往返和重复台词，不削减主线必要内容。开场总览目标 15–20 秒。
- 复用素材与引擎；本轮不引入新的数值、等级、经验条、技能树、背包、独立任务列表或新历史分支。
- 下述任务步骤保留为原始验收依据；实际实施与发布状态见本文开头及部署记录。

逻辑链：主线选择／地图发现 → StateSystem 一次性记录与属性变化 → 成长门槛 → 途中人物回应＋活动开始快照 → 玩家操作及有限帮助 → 真实成绩与具体经历进入结局。
