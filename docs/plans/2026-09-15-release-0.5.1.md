# 0.5.1 实施与验证计划

**目标：** 完成本次设置精简、交互调整、属性教学、保皇派透明底修复和高俯视 Q 版美术，本地归档 0.5.1。

**实现：** 复用三维主线的状态与交互生命周期。教学在主线节点完成时按实际奖励触发，所有新文案同改中英；俯视美术使用版本化新原件、沿用角色与方向索引，在镜头可调范围最高 30% 切换，脚底锚点保持一致。

## 分项

1. `Demo.ts`：删除设置装饰句，标题与入口统一为设置；标题显现半径减半，实际交互半径保持。
2. `GrowthGuide.ts` / `StoryUI.ts` / `StoryDirector.ts` / `growth.ts`：首次报童奖励教影响力、街头争论奖励教锐气，首次伯尔交互教双关系，首次华盛顿交互教信任；检查暂停、重开和四种语言。
3. `StoryPlaces.ts` / `discoveries.ts`：广场货架旁的面包交互、喷泉右侧伯尔，删除军营文件签名及悬空依赖。
4. `portraitPixels.ts`：检查真实图集的灰矩形成因，共享透明底与边缘恢复流程修复，保留生成原件。
5. `public/art/actors/high-angle-v1/`、`PixelAtlas.ts`、`PixelActor.ts`、`StoryNpc.ts`、`CameraOrbit.ts`：参照现有四张 Q 版图集生成高俯视整套方向及动作，自动切图与镜头倾角共同消除二次挤压。保留八向、步行动画、交互命中与影子。
6. 浏览器检查设置、教学、两种视角、地图目标与透明背景，保存截图；运行 `npm test` 和 `npm run build`。
7. 更新 `package.json` / `CHANGELOG.md` / `README.md`，执行 `npm run release:pack -- --notes '具体变更'`，保留网站及源码压缩包；线上切换另待授权。

## 验收重点

- 视角阈值是 `.43 + (.98 - .43) × .7 = .815 rad`（约 46.7°）。切换不重新创建场景或改变人物位置。
- 所有场景使用同一高俯视美术规则，报童保持较小体型。
- 属性教学不朗读为旁白，内容只保留用户指定说明。
- 已归档 0.5.0 原封保留。
