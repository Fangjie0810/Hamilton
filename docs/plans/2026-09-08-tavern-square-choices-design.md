# 酒馆自由交谈、选项预览与室外边界

用户确认“第三幕”指公开辩论广场。实施沿用现有剧情、检查点与移动系统。

酒馆允许任意顺序开始尚未完成的互动，分别记录三人的完成状态。仅当前交谈拥有回答和计时，完整读完回应后才计为完成，三人全部完成才开放出口。超时仍记沉默，重开恢复入场状态并清空本幕完成集合。其他章节保持原先顺序。经典版与 3D 同步。

酒馆回答时间从 5000 ms 改为 10000 ms，由共享常量提供给规则、进度条、辅助属性和文案。暂停、语言切换不消耗或重置时间。辩论的 2.5 秒选牌及军令、节拍等独立活动参数沿用原值。

每个剧情问答选项依据其真实 effect 显示对应指标与绿↑/红↓，不公开增减点数。伯尔尊重、伯尔竞争、华盛顿信任分别命名。箭头表达数值方向，不对角色立场作好坏评价；受 0–100 边界限制而无实际变化时显示中性的横线。颜色以外同时使用方向符号及双语辅助标签。直接使用当前状态计算预览，不能在预览时应用 effect。

广场采用向镜头远处延展的地面与街区，保留原 32×28 的剧情行走区域，并把可见护栏与碰撞一同建立。相比扩大所有寻路网格，单独延伸模型能补全视野而不改动剧情距离；相比禁止转镜头，可以保留自由观察。其他室外地面和水岸也延伸，军营与约克镇边界补上护栏。

验证包括六种酒馆排列、十秒计时边界、超时与重开、18 个选项的预览和实际效果一致、真实浏览器完整主线、三语言小窗口，以及室外远镜头和旋转视角。缺失素材单独盘点，不改变素材清单来假装资源已经存在。
