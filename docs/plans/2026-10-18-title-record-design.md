# 标题页唱片播放器

需求：标题主页面显示旋转唱片，播放本地已有 BGM，以对应歌曲名称展示，并有点击切换提示。

现有资料：`public/audio/bgm/manifest.json` 保留七首原始文件名和哈希；MP3 未提供内嵌标题标签。英文显示名沿用现有曲目对应关系并规范大小写；依照用户最新要求，所有语言模式都显示英文原名，不提供译名。

交互：右下角黑胶唱片搭配金色纸标、当前歌名与简短提示；播放时旋转，暂停、静音、缓冲或自动播放被拦截时停止。不显示「原声唱片」标题；点击唱片直接切换下一首，不提供选曲列表，保留独立播放/暂停按钮。按顺序播完自动换下一首，到末首回到首首。首次自动播放受阻时提供明确点击入口。小窗口使用正常文档流，避免挡住启程和页脚。

复用 `MusicSystem` 的单一音频元素、音量偏好、失焦与隐藏暂停；只为标题页增加播放列表模式。进入游戏同步结束预听并从零播放既有序幕 BGM，沿用两秒按钮反馈、CG、章节生命周期和剧情内循环。语言切换不换曲、不重置播放进度。减少动态遵循系统设置。

验证：为播放顺序、自动前进、下一首、拒播恢复、暂停/音量和启程交接增加音乐系统测试；浏览器检查真实播放、下一首、四语言、小窗口、减少动态及进入 CG。运行 npm test 与 npm run build。

实施与验收：
- `src/data/music.ts` 增加成对曲名与标题页播放顺序；原 MP3 文件及哈希不变。
- `MusicSystem` 增加标题播放模式与状态订阅，保持游戏内单曲循环、辩论位置恢复及多原因暂停。处理自然结束与手动切歌淡出同时发生的情况。
- `TitleRecord` 显示实际播放/暂停/加载/静音/拒播/失败状态，离开标题页时解绑监听。
- 初版 `npm test`：199/199 通过；`npm run build`：双语、TypeScript、生产构建通过。
- 初版浏览器验证：拒播恢复、七首选曲、暂停/恢复、四种语言、小窗口及 CG 交接通过；该选曲交互已按最新要求移除。
- 最新简化版：199/199 测试通过，双语检查、TypeScript 与生产构建通过。浏览器确认点击直接下一首、连续点击及末首回首曲；四种语言下歌名均为英文且标注 `lang=en`，提示随主语言切换，选曲面板与唱片标题均已移除。390×844 的两种双语模式与 1280×800 宽屏显示正常；真实播放状态为 `playing` 时唱片旋转，暂停后停止。浏览器未记录控制台错误。
