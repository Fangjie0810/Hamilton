# 语言选项与 CG 音量

按用户明确要求：语言入口使用目标语言本身显示。四个选项固定为“双语 · 中文主字幕”、Bilingual · English first、中文和 English；实际文案仍在 i18n 配对维护，只在选择器输出目标语言。标题按钮、标题设置和游戏暂停设置共用选项，保持当前语言与字幕切换流程。

CG 播放器新增 0–100% 独立音量，初次默认 60%，浏览器保存调整值。复用现有音量滑块，支持百分比与键盘操作。静音开关与选定音量独立，调节不重播或解除暂停。片尾及跳过的渐隐增益乘以个人音量，避免进入片尾时突然恢复 100%。保持原 CG 与游戏入场生命周期。

验证：npm test、npm run build；浏览器验证四种模式的自语言标签、手机布局、实际视频音量、暂停/键盘/静音/记忆、自然片尾与跳过渐隐。
