# 场景中的主线：首阶段迁移

用户希望逐步把完整游戏流程转移到三维场景之间。本阶段以完整可通关流程为交付边界，保留原版入口和自由漫游入口。

## 交付结构

- `StoryProgress`：纯状态；复用 chapters、StateSystem、DialogueCursor、活动结果效果，控制互动顺序、选择、酒馆时限、出口解锁和检查点回滚。
- `StoryPlaces`：将十二段原互动映射到六幕中的真实 XZ 站位；NPC 与可站立点分开，具备碰撞；序幕借纽约码头上的信回顾过海经历。
- `StoryDirector`：章节加载、NPC、目标、环境点击与状态之间的桥梁；异步章节切换/重启使过期活动回调失效。
- `StoryUI`：中英对话、打字、限时选项、状态和结局；直接复用 DebateActivity/WritingActivity/YorktownActivity，状态写入仍集中在 StoryProgress。
- `Demo`：共享渲染、寻路、输入和资源生命周期。漫游模式直接切场景；主线模式锁定章节顺序、完成后通过出口进入下一处。

## 选择

保留现有完整剧情与成绩规则，先迁移承载它们的场景。避免另外重写一套简短对话造成两种版本内容分叉；也避免同时重写所有战斗导致主线无法完整验收。新增人物使用与已有 Hamilton/Burr 一致的像素素材，六角色五视角原图通过镜像提供八方向待机。

## 本阶段范围

三维行走和人物互动 → 对话与选择 → 当前场景上的活动面板 → 结果记录 → 出口解锁 → 下一场景 → 完整结局。阶段结束后，首选下一步是将约克镇潜行投射到实际工事路线与队伍，再改造讲台节拍表现、军令桌操作和角色动作。此后才考虑自由跨幕回访；现在的主线保持既有顺序，漫游模式提供自由切换。

## 验收

真实碰撞地图上的全部互动/出口均可达；不能跳过主线；对话、限时选项、活动暂停与中英切换不丢状态；章节重启恢复入场状态且不重复奖励；成功与故意失误路线均能结算；图片色键、脚底和八方向正确；1024×640 可操作。
