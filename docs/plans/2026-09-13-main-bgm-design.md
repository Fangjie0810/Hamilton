# 主线 BGM 接入

用户提供 `/Users/fangjie/Desktop/ham BGM ` 中的 7 首歌曲，并明确六个章节及辩论小游戏的映射。沿用三维主线和既有 550 ms / 2875 ms（减少动态为 250 ms）转场参数。

- 原始 MP3 按字节复制到 `public/audio/bgm`，规范化文件名；清单保留原名、大小和 SHA-256。
- `src/data/music.ts` 保存六章节及辩论曲映射；`MusicSystem` 复用单个音频元素，避免重叠并沿用点击启程的浏览器播放授权。
- 启程点击同步启动 Alexander Hamilton。加载三维引擎、呈现 CG、序幕标题与移除遮罩均不重置此曲。
- 普通章节在 `switchScene` 开始暂停，在遮罩移除及暂停状态恢复后起播新曲。直接加载主线从序幕遮罩移除后请求播放；浏览器拒播等待真实输入。
- 辩论活动进入时保存 Farmer Refuted 的时间并切换 Cabinet Battle #1，活动完成后恢复前者位置。重开本幕清理临时曲及旧位置，退出游戏或进入结局停播。
- 通过不同暂停原因共同控制暂停，解除一个原因不会越过仍存在的设置/失焦/隐藏/影片暂停。影片静音只临时静音 BGM，退出影片恢复；字幕切换不调用音乐系统。
- 默认循环、35% 基础音量；背景音乐双语开关独立保存，原有配音及影片原声继续使用既有系统。节拍参数和成绩不绑定 MP3。

验证：单元测试覆盖跨序幕连续播放、章节与重开、辩论恢复、暂停叠加、播放拒绝与过期 Promise、媒体失败和原始文件校验。真实浏览器检查 MP3 解码、原生循环、启程/跳过、双语设置和转场；全流程检查六章/三个活动及全部七首曲目。

数据链：启程/章节/玩法阶段 → 曲目映射 → 单一循环播放器 → 暂停原因与设置 → 本地 MP3；剧情和成绩沿用原状态系统。
