# 像素人物八方向扩充

用户要求把当前三维样例的人物从四方向补到八方向。沿用已有像素人物设计和正、背、侧面的素材，补画斜前与斜后，每个新方向有待机和四帧行走；左右通过镜像覆盖八方向。伯尔补足各方向待机，并在玩家靠近时面向玩家。

新增一张 5 列 × 3 行的补充图集：第一行 Hamilton 右前待机 / 四帧步态，第二行右后待机 / 四帧步态，第三行 Burr 后 / 右后 / 右 / 右前 / 前待机。保留原图集，运行时统一裁切与脚底原点，组成 8 列 × 4 行纹理。

方向由角色世界朝向和镜头水平角转换到屏幕角度，再划分为八个 45° 扇区。边界保留 3° 迟滞以减少抖动；停步保留朝向，转动镜头也能看到相应方向。步态继续由实际位移驱动。

验证八方向映射、镜头旋转、跨角度边界稳定、镜像、步态与待机帧，以及 NPC 朝向。浏览器实际检查八组键盘输入、斜向停步、镜头环绕和对话；运行完整逻辑测试、中英配对检查和构建。新素材保留原图与生成提示。

链条：世界朝向 + 镜头角度 → 八方向选择 → 待机 / 距离步态 → 对应图集与镜像 → 原有三维光照和遮挡。
