# 中英文与转场

用户要求：幕间渐隐渐显为原来的 2.5 倍，游戏增加英文，设置可选中文 / 英文 / 双语，默认双语，以中文为主、英文为副字幕。今后的文字素材必须中英文同步维护。

实现：剧情及玩法数据使用必填 zh/en 成对文本；动态反馈使用双语模板与共同参数。DOM 文本和 Phaser 标签监听语言变化，原地更新，不重建场景或重置进度。对话两种语言按相同比例显示，切换语言保留显示进度；设置保存在独立 localStorage 键中。

转场：普通渐入/渐出 220 → 550 ms，标题等待 1150 → 2875 ms，减少动态设置下等待 100 → 250 ms。游戏输入在完整转场期间保持锁定。

验证：配对文本完整性、模板参数一致性、三种模式与存储回退、转场时间；浏览器验证默认双语、实时切换、英文完整通关、暂停保留计时、小窗口双语布局。新增语言规则写入项目 AGENTS.md，并接入构建检查。
