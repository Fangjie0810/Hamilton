# 启程反馈、半尺寸 CG 与属性盘出现时机

用户要求：启程有明显的点击反馈，使用已有点击时音频；停留 2 秒后渐隐切换 CG；CG 为此前宽高的 50%，居中且周围黑底；战役徽章属性盘在序幕隐藏，第一幕才出现。

## 实现

- 启程按钮一次性放大、亮边，立即调用现有 `music.beginJourney()`，不叠加新的点击音频。重复点击不能重复创建音乐或影片。
- `OpeningFilm.coverEntry()` 保留 2 秒标题画面，然后使用原来的 550 ms 渐隐（系统减少动态时为 250 ms）；2 秒停留不随减少动态缩短。
- 在点击手势内以零音量预备同一个视频元素，播放画面前恢复到首帧与用户保存音量，保持浏览器音频激活能力。等待期间失焦也保持暂停，回到页面后可手动继续。
- 全屏黑底容器居中显示宽高各 50% 的视频，继续使用 `object-fit: contain`。原始剪辑、片尾标题、音量、暂停、跳过与错误恢复保留。
- `StoryUI.updateState()` 依据当前章节隐藏／显示属性盘；序幕读信结束后仍隐藏，Arrival 开始显示。原数值、成长反馈与说明逻辑保留。

## 验证

- `npm test`：183 项通过；`npm run build`：双语检查、TypeScript、生产构建通过。
- `scripts/opening-film-check.mjs`：点击音频启动、2 秒停留、真实渐隐、桌面／小屏半尺寸居中黑底、完整 57.2 秒播放、四语言、暂停、跳过、网络失败及自动播放被拒后的恢复。
- `scripts/campaign-compass-check.mjs`：实际读完序幕并进入 Arrival，序幕无圆盘、第一幕显示；五区原有交互及四语言检查通过。
- `scripts/entry-feedback-check.mjs`：按钮放大及亮边样式、重复点击保护、等待阶段失焦、首帧暂停／继续／跳过与控件清理均通过。
- 输出保存在 `artifacts/intro-review/` 和 `artifacts/campaign-compass-*`。

流程：点击与现有音频 → 按钮反馈停留 2 秒 → 标题渐隐 → 半尺寸 CG 从首帧播放 → 无属性盘的序幕 → 第一幕显示战役徽章。
