# Three expanded scenes Implementation Plan

**Goal:** 提供纽约街头、酒馆和舞会的可操作 3D 验收页，空间更大，室内通过真实门洞连续进入，每场景四件中英配对的角色收藏品。

**Architecture:** 在现有 Vite 项目中增加 `?experience=3d` 按需加载入口；复用 Walker、WalkMap、PixelActor、StoryNpc、Occlusion、CameraOrbit 和 i18n。三套新世界和收藏品只属于验收模式，不改变已有剧情检查点与正式章节顺序。室内与室外属于同一个世界；只有主动切换三个大场景才换世界。收藏品状态使用独立版本化本地存储，未来剧情线索保留稳定 ID 与 tags，不伪装成已实现的分支效果。

**Tech Stack:** Three.js、TypeScript、Vite、现有像素图集；无新增依赖。

## 执行任务

1. 建立 `src/sceneExperience/data.ts` 和 `state.ts`：三场景、可达站位、十二件物品、原创附文和后续线索标签；测试存储损坏回退、重复拾取、开关不清空收藏。
2. 建立 `SceneryKit.ts`、`Worlds.ts`：模块化可进入建筑、内部家具、门洞、墙／屋顶遮挡、装饰远景，新增三套实际模型；自动测试从出生点到所有地点／藏品站位可达，实际 Walker 能穿门往返。
3. 建立 `Experience.ts` 与 `experience.css`，接入 `src/main.ts`：场景切换、WASD／鼠标行走、镜头旋转／缩放、地点导览、收藏品开关／图鉴／本场重置；完整语言模式与暂停、失焦处理。
4. 本地浏览器实际检查三个场景、室内透明、碰撞、收藏和四种语言；保存截图，按结果修正构图与可读性。
5. 执行 `npm test`、`npm run build`，更新交付文档和 README，保留本地预览入口。本轮不部署、不升级发行版本。

## 验收重点

- 街头约 64×50、酒馆约 40×32、舞会约 48×38 世界单位；以实际可走面积和房间内容验收。
- 街头印刷店、布料铺、仓库；酒馆储酒间、后厅；舞会侧室均使用同一场景内的敞开门户。
- 门洞、地板与碰撞一致；屋顶进入后隐藏，阻挡视线的墙使用既有遮挡逻辑；不能整栋楼与家具一同消失。
- 三场景各四件独立造型的角色物品；E 或近距离按钮查看与收集；图鉴可回看；关闭后模型、标记与拾取全部关闭，已有收藏保留。
- 所有玩家可见文字使用 bi／f 和 setText／setLabel；不新增旁白、不接入未确认音游或分支结局。
- 工作目录无 Git 元数据，改动在现有目录执行并留文件快照；不虚构提交。
