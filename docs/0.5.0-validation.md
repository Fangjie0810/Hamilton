# 0.5.0 本地大版本 · 合并与验收

2026-09-15。用户确认左侧圆盘方案并要求合并、记录一个大版本。按项目的测试版本规则，从 0.4.1 升至 **0.5.0**；未执行上传或线上切换。

## 最终行为

- 直接复用战役徽章 HUD 的 `CampaignCompass`，左上边缘固定，通常放大至原来的 150%（桌面 174 → 261 px）。动画约 3.5 秒：放大、分区发亮及数值／填充同步过渡、恢复原大小。
- 每笔 `StateChange` 保存完整前后快照，多项一起显示、连续提交依次播放；98 加 8 采用真实 +2。零变化不播报，七个数值项均有中英文标签。
- 游戏暂停冻结动画及队列，正常换章与结局保留未播完变化，章节重开、新局与销毁清理旧变化。序幕不显示圆盘。
- 数值标签只显示当前主语言，系统减少动态采用左侧淡入淡出。小窗口有必要时缩小以避让对白正文。
- 首次成长说明等圆盘恢复后展示；已显示说明在圆盘放大期间暂时隐藏并冻结阅读时间，避免同一区域叠放。

## 合并边界

此前实验目录是较早的独立源码快照，不能整体覆盖主目录。本次仅新增 `src/attribute-feedback/` 中的圆盘组件、时间线与样式，修改 `StoryUI`、`StoryDirector` 生命周期接入及 `CampaignCompass` 过渡数值取整。

合并前后源码哈希对照确认，其他主源码未被本次移植改写。最新报童对白与配音、完成首次报童交互后才出现的视角／奔跑教学、精简后的回应选框、保皇派与市民主像素修图均保留。不引入实验评审入口、示例状态修改工具或被否定的三版样式。当前项目没有 Git 仓库，本次合并指逐段移植到主项目；版本由不可覆盖的网站和源码归档封存。

0.5.0 同时收录 `CHANGELOG.md` 中此前未归档的启程两秒反馈、居中半尺寸 CG、序幕隐藏圆盘、战役徽章与第一幕交互改进。
