## 高俯视美术与纹理生命周期

- 使用内置 image_gen，以原 Q 版图集为参照重新绘制四张图集，共 86 个原始方向／动作格；包含 Hamilton、Burr、报童、保皇派、Laurens、Lafayette、Mulligan、Washington、市民。方向映射复用现有八向系统，Hamilton 步态与街头争论动作保留。
- 阈值按 `.43 + (.98 - .43) × .7 = .815 rad` 计算，约 46.7°。高俯视画面已有自然缩短的身体透视，绘制平面朝向镜头，避免三维投影再次压扁；规范化体高为原 75%，脚底保持 120 px 支点。
- 不替换场景、人物根节点、世界坐标或寻路碰撞。贴图源切换前释放旧 GPU 绑定，随后上传目标图集，避免共享纹理被连带替换，以及换章释放时的 Three.js 缓存错误。
- [完整生成提示与原件目录](art/high-angle-pixel-0.5.1.md)。[主像素透明底修复记录](art/verification-0.5.1/portrait-matte.md)。

## 归档与复现

运行 `npm run release:pack -- --notes '0.5.1：设置与交互标题精简、首次属性教学、主像素透明底修复、高俯视Q版图组、广场位置与军营交互调整；仅本地归档'`。

此命令在打包前再次执行游戏测试、发布工具测试与生产构建。输出目录 `releases/0.5.1/` 包含 `ham-0.5.1.tar.gz`、`ham-0.5.1-source.tar.gz`、逐文件清单 `release.json` 与 `SHA256SUMS`。旧版 0.5.0 独立保留。

浏览器专项使用已安装的 Playwright，设置 `HAMILTON_PLAYWRIGHT_MODULE` 为其入口绝对路径，`HAMILTON_BROWSER=chrome`，启动本地服务后运行上述脚本。

逻辑链：主线交互完成 → 真实奖励与状态快照 → 对应简短教学；镜头俯角 → 新旧图组及绘制面朝向 → 稳定脚底；回归验证 → 0.5.1 网站与源码归档。
