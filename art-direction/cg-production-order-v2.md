# CG 后续制作顺序

> 2026-09-10：最终编剧、7镜首帧、提示词及方舟操作步骤已完成，请以 [v3 操作手册](cg-final-prep-v3/操作手册.md) 为执行入口。下文保留为早期制作顺序记录。

2026-09-09。用户在看到 v2 实景试帧后表示“可以”，并询问制作顺序。本次将破旧、湿热、有人实际生活和劳动的加勒比电影影像作为后续方向；该反馈不等于全片剧本、各镜头造型和动态连续性已定稿。

## 1. 定最终分镜脚本

先从比较方案收束到一版。建议以约60秒、6–7个镜头作为工作规模，最终以叙事需要确定。商行优先作为开场候选；确定童年经历如何进入、风灾如何连接到写作，以及文章被读到和获得支持如何导向离岛。每镜写明时空、动作起点与终点、预计成片时长、切点和环境声。不能将三张质感试帧直接当作完整故事。

通过标准：没有对白和字幕解释，也能辨认关键时间变化与因果关系。若童年回忆难以读懂，应在分镜阶段调整顺序。动作是具体的行为，不用低头、悲伤、希望等抽象情绪填满时长。

## 2. 按新质感锁定人物和服装

根据最终剧本需要，准备童年与少年两个年龄造型；固定面部关系、发型、体型、衣装剪裁、旧损位置与携物方式。母亲等配角只有在镜头需要辨认面容时才新增身份参考。自然光下记录必要的正面、侧面、全身，避免继承旧参考板的精修布光。

现有商行和码头成图主要是背侧，不能证明面容一致。还需明确各时期衣装允许变化的范围、同一场景跨镜必须保持的细节。外观参考与场景光线各有用途，不能把一张头像当成首帧，也不能把环境试帧当成完整人物设定。

## 3. 做小规模动态验证

先准备商行正式首帧，制作一条10–12秒试拍。沿用已举到账架前的动作起点，放稳、松手、退半步；机位固定，检查重量、手与书的接触、衣服变化、画面是否擅自漂移及可用时长。实际放置区必须干燥且可达，不能把书移到漏水处。

商行通过后，试一条能看到面部与执笔手的灾后写作镜头，检验跨镜人物身份、纸笔接触及细小动作。写作是故事转折，不能在批量阶段才发现关键动作无法使用。先展示上一条结果，再安排下一条；播放顺序和制作验证顺序可以不同。

## 4. 补齐正式首帧，先做静态粗剪

用统一后的参考图补齐各镜头首帧，按分镜计划在时间线上各停留相应秒数，配临时环境声判断顺序、停顿和总长。涉及复杂位移时增加动作示意或关键位置草图；无须机械地给每镜生成尾帧。这个版本只检验叙事节奏，不用数字推拉假装镜头已拍成。

通过标准：能看懂事件发展、段落有长短变化，最后一个镜头与进入第一幕的画面及声音有明确衔接。静态粗剪仍不能验证动态质量。

## 5. 按镜头分批生成视频

每条素材保持用户要求的10–20秒范围，优先10–15秒，以最终采用工具支持范围为准。提示词只组织一个主要动作；逐条检查面容、服装、接触关系、背景人物、动作起止及镜头稳定后再继续。失败时修正对应镜头，保留成功素材。

生成时长不等于成片使用时长：从每条中选最自然的片段，不强行每镜等长，也不通过慢动作补时。进入这一步前确定视频工具与输入格式，再适配实际参数；当前未指定平台，不把某一模型能力当成既定条件。

## 6. 剪辑、声音和第一幕衔接

先做画面粗剪，再完成环境声、拟音、基础曝光与色彩统一。雨、纸、笔、脚步、木板、绳索与水声参与切点设计。默认舍弃生成器音轨，另行建立可控声音；全片无对白、独白、配音、歌唱或可辨认人声，不依赖字幕解释。

先验收独立短片，再确定接入项目中的位置、末镜声音衔接和转场。若接入游戏需要改动代码，才进入相应项目测试与构建流程；当前阶段不修改游戏。

## 当前下一项交付

最终一版分镜表：每镜一行，含内容、时空/年龄、人物动作起止、机位理由、生成时长、预计成片取用、切点和声音。图像方向使用 [v2 试帧](cg-opening-frames-v2.md)，旧舞台方案仅留档。

制作链：最终分镜 → 人物与衣装基准 → 商行及写作动态验证 → 全片首帧与静态粗剪 → 分批视频 → 剪辑、声音与第一幕衔接。
