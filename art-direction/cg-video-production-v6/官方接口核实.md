# Seedance 2.5 视频生产接口核实

核实日期：**2026-09-11，北京时间**。先复核 v3 核实记录，再读取火山方舟公开文档当前正文。本记录没有读取 API Key、调用账户接口或创建任何视频任务；下面的请求体与费用均为生产准备，**本轮未实际生成视频**。

## 接口与首帧参数

| 项目 | 本次已核实结果 |
| --- | --- |
| 模型 ID | `doubao-seedance-2-5-260628`。也可使用账户实际有权限的 Endpoint ID，不能虚构接入点。 |
| 创建任务 | `POST https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks`，异步返回任务 ID；本轮不执行。 |
| 首帧输入 | `content` 内放一个 `type: "image_url"` 对象，图片地址位于 `image_url.url`，显式设置 `role: "first_frame"`。 |
| 图片输入方式 | 公网 URL、Base64 Data URI 或适用的素材 ID；本地 PNG 可传 `data:image/png;base64,<原始文件字节的Base64>`。 |
| 首帧比例 | Seedance 2.5 首帧／首尾帧模式默认且**仅支持** `ratio: "adaptive"`，跟随首帧比例。现有 2560×1440 首帧为 16:9。 |
| 时长 | `duration` 为整数 4–30 秒，或 `-1` 自动选择。生产计划应明确每镜秒数以便预算，不使用自动时长。 |
| 分辨率 | `480p`、`720p`、`1080p`，默认 `720p`；2.5 不支持 `4k`。16:9 对应 720p 为 1280×720，1080p 为 1920×1080。 |
| 关闭声音 | 显式 `generate_audio: false`；默认值为 `true`。关闭后无生成的人声、音乐及环境音，后期声音需另制。 |
| 容器 | `output_format: "mp4"`，另支持 `mov`。本计划采用 MP4。 |

来源：[Seedance 2.5 官方教程](https://ark.volcengine.com/region:cn-beijing/docs/82379/2607688?lang=zh)、[创建视频任务 API](https://ark.volcengine.com/region:cn-beijing/docs/82379/1520757?lang=zh)。

单张图片须小于 30 MB、每边 300–6000 像素、宽高比 0.4–2.5；完整请求体不得超过 64 MB。Base64 会增加传输体积，应按编码后的请求体检查大小。首帧、首尾帧和全模态参考是不同场景，本计划不混入 `reference_image`。不要套用旧模型的 `camera_fixed`、`seed`、`draft` 或离线推理参数。[创建任务字段及限制](https://ark.volcengine.com/region:cn-beijing/docs/82379/1520757?lang=zh)

仅供审阅的最小请求体：

```json
{
  "model": "doubao-seedance-2-5-260628",
  "content": [
    {
      "type": "text",
      "text": "此处替换为已审定的单镜头动作与机位提示词。无对白、独白、歌唱或字幕。"
    },
    {
      "type": "image_url",
      "image_url": {"url": "data:image/png;base64,<原始PNG的Base64>"},
      "role": "first_frame"
    }
  ],
  "resolution": "720p",
  "ratio": "adaptive",
  "duration": 12,
  "generate_audio": false,
  "output_format": "mp4"
}
```

## 编码与实际成片检查（本批用户已选择720p）

官方分辨率说明明确：Seedance 2.5 的 1080p 输出采用 **10bit 位深、H.265／HEVC 编码**。因此 MP4 扩展名不能作为所有浏览器都能解码的保证。后续应保存生成原件，再检查实际尺寸、帧率、时长、像素格式、编码和音轨；需要时另外导出播放兼容版，保留原件。[2.5 输出规格](https://ark.volcengine.com/region:cn-beijing/docs/82379/2607688?lang=zh#2.5_video_output_specs)

另一个 `output_format` 段落将 MOV 描述为 H.264＋yuv444p＋PCM 的专业格式，因此不能把 MP4 的编码预期原样套到 MOV，也不能仅凭 10bit 就认定文件带有特定 HDR 传递函数。当前计划不改用 MOV；实际文件信息以下载后检测为准。[容器格式说明](https://ark.volcengine.com/region:cn-beijing/docs/82379/1520757?lang=zh)

文档使用“总帧数 ÷ 24，向下取整”说明 API 的 `duration` 返回值；查询接口另有 `framespersecond`。因此下方预算采用 24 fps，但最终剪辑不能只依赖整数 `duration`，应检查实际帧数和媒体时长。[创建任务时长说明](https://ark.volcengine.com/region:cn-beijing/docs/82379/1520757?lang=zh)、[查询任务返回字段](https://ark.volcengine.com/region:cn-beijing/docs/82379/1521309?lang=zh)

## 138 秒生成素材的费用估算

本项目是图片首帧生视频，**输入不含视频**。Seedance 2.5 按视频 token 计费，不能用 Seedream 的图片单价，也不能套用 Seedance 1.5 pro 的有声／无声两档价格。`generate_audio: false` 不改变 2.5 本表使用的单价类别。[官方模型价格](https://ark.volcengine.com/region:cn-beijing/docs/82379/1544106?lang=zh#sd25_price)

官方估算公式：

```text
估算 token =（输入视频秒数 + 输出视频秒数）× 输出宽 × 输出高 × 帧率 ÷ 1024
估算费用 = 估算 token ÷ 1,000,000 × 每百万 token 单价
```

以下按 **138 秒生成总量、16:9、24 fps、没有输入视频**计算；不是按后期保留下来的成片时长收费。

| 规格／价格时间 | 估算 token | 单价（元／百万 token） | 138 秒预估 |
| --- | ---: | ---: | ---: |
| 1080p，2026-09-11 适用的公开 72 折 | 6,706,800 | 55.44（77 × 0.72） | **¥371.82** |
| 1080p，刊例价 | 6,706,800 | 77.00 | **¥516.42** |
| 720p，公开价 | 2,980,800 | 70.00 | **¥208.66** |

1080p 优惠有效期为 **2026-08-14 14:00 至 2026-09-17 14:00，北京时间**；480p／720p 不参与该优惠。若批准后的执行时间超过期限，应重新核价。官方只对成功生成的视频计费；成功重拍会增加费用。准确用量以任务返回的 `usage.completion_tokens` 为准，最终扣款以实际账单为准；本表未假定资源包、账户专属优惠或免费额度。[公开单价、优惠期限及计算公式](https://ark.volcengine.com/region:cn-beijing/docs/82379/1544106?lang=zh)

## GET /models 能证明什么

本记录没有读取密钥或调用 `GET /api/v3/models`。如果后端另做只读检查，并得到 HTTP 200 且列表中出现该模型 ID，可以如实记录“该次模型列举请求成功，响应包含该 ID”。它证明了**该次请求的连接与列举结果**，不等于已验证视频创建、模型推理权限、余额、人像审核、排队配额或输出成功。

本次未找到明确承诺“`GET /models` 列出的每个模型均已为当前账户开通且保证可推理”的官方接口契约，因而不作该承诺。官方仍单独定义 `ModelNotOpen`、`InvalidEndpointOrModel.ModelIDAccessDisabled`、`AccessDenied`、`AccountOverdueError` 等错误；模型服务开通、调用方式权限、账户费用和内容审核是不同条件。[官方错误码](https://ark.volcengine.com/region:cn-beijing/docs/82379/1299023?lang=zh)

## 受信任原图与 Data URI 的边界

官方列明：**本方舟账号近 30 天内，Seedream 5.0 lite／pro 纯文生图得到的含人脸原始图片**，可以作为 Seedance 2.5 的受信任输入。跨账号、跨平台、超期或二次剪辑的含人脸产物不满足该豁免；压缩、转发可能使信任失效。TOS 是官方建议的保存与使用方式，文档没有规定必须使用 TOS。[官方人像信任规则](https://ark.volcengine.com/region:cn-beijing/docs/82379/2608626?lang=zh#trust-model-output)

创建 API 明确允许把本地图片编码为 `data:image/png;base64,...`。**将保存的原始 PNG 字节编码成 Base64 是可逆的传输表示，不会修改图片字节**，因此本计划可以保留原件及 SHA-256，按原始字节构造 Data URI。这里区分两件事：API 接受 Data URI 是已核实规则；人像信任识别能否在本次具体上传中成功，仍须待用户批准后的首次实际创建结果确认。官方没有在信任教程中单独保证 Data URI 路径必然识别成功，不能提前写成已通过审核。[图片输入格式](https://ark.volcengine.com/region:cn-beijing/docs/82379/1520757?lang=zh)、[信任范围及注意事项](https://ark.volcengine.com/region:cn-beijing/docs/82379/2608626?lang=zh#trust-model-output)

不含人脸的环境图片不涉及上述人脸信任问题，官方明确允许剪辑后用于二次创作。因此无人物 E03 的局部修改无需冒充纯文生图原件；记录真实来源即可。即使输入享有信任，输出仍可能触发内容审核。[官方人像教程](https://ark.volcengine.com/region:cn-beijing/docs/82379/2608626?lang=zh#trust-model-output)

后续数据链：**审定镜头方案与预算 → 核对首帧原件和账户只读结果 → 用户批准生成 → 创建并保存任务 ID → 查询完成并下载原件 → 检查实际媒体信息与动作 → 剪辑交付**。本轮工作止于方案与接口准备，不执行付费视频 POST。
