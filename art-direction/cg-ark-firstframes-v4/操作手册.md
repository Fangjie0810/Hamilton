# 图片选定后的生成设置

如果在方舟页面手动执行，每个镜头各建一个视频生成任务：选择Seedance 2.5，将 firstframes/Sxx.png 原始文件设为首帧，粘贴 prompts/Sxx.txt 全文，再按下表设置时长。使用16:9，沿用已测试的720p，关闭音频生成。不要用审阅页截图、缩略图或另存压缩后的图片替代原图。

API批量生产时同样只读取这一套首帧和提示词；图片顺序不依赖生成时的返回顺序。若某镜出现明确报错，保留原请求结果定位该镜，不重跑已经成功的其他镜头。请求超时而没有明确状态时，不假定失败并立即重复提交。

# 剪辑衔接

S01到S02采用同构图硬切，让同一照料动作与空床形成呼应，不用人物消失特效或叠化。S02到S03以手和被承托的物件连接童年与少年。S03到S04在账册稳定后切到风压；S04到S05由紧绷身体切到安静写作。S05到S06把笔停下与信被阅读相连。S06到S07以深色补丁旅行袋连接实际资助和离开。

需要环境声时，在后期独立加入少量陶碗触木、滴水、木板、衣料和港口水声，不生成对白或旁白。画内不烘焙叙事文字。结尾由项目接入时统一处理淡出和三维第一幕衔接，生成片段本身保留空舷梯。

参考 [制作说明.md](制作说明.md) 的首帧来源与当前限制；本版替代v3中与新首帧冲突的持物动作。执行顺序：看完整套图片 → 定下镜号 → 一次性安排7段视频 → 下载逐段检查 → 按动作剪成开场CG。
