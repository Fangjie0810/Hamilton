> 最新进展：用户已用方舟新首帧成功生成S05，认可除字迹外的整体效果。下一步是书写修正和S07动作测试，详见 [首条视频评审](reviews/S05-test-01/评审.md)。原任务清单尚未替换为全套正式首帧，暂不执行全片生产。

最终方案：7镜顺叙，生成90秒素材，剪辑目标68秒。照料母亲 → 空床 → 商行谋生 → 风灾 → 写作 → 获得支持 → 登船。

1. 解压完整文件夹，双击 `START-HERE.html`。每镜可看图、下载首帧、复制完整提示词。
2. 在火山方舟 Seedance 2.5 首帧模式先测试 S05：上传 `firstframes/S05.png`，复制 `prompts/S05.txt`，12秒、720p、自适应画幅、关闭声音。
3. S05通过后测试 S07：同样操作，时长改为15秒。再按手册进入API批量生产与剪辑。

完整编剧、参数、切点、环境声、错误处理和命令均在 [操作手册.md](操作手册.md)。当前只完成前期准备，未生成视频或提交方舟任务。

| 文件 | 用途 |
| --- | --- |
| `firstframes/` | 本次应上传的7张单幅首帧；不要上传拼版或旧版图片 |
| `prompts/` | 本次应复制的7份完整视频提示词 |
| `manifest.json` | API唯一任务清单，记录图片、提示词、时长和剪辑区间 |
| `edit-decision-list.csv` | 剪辑参考表，按实际动作微调，不是自动导入用EDL工程 |
| `api/` | 批量创建、恢复查询和下载工具；默认离线预览 |
| `fallback-seedream/` | 仅在人物输入被拒绝时使用的方舟文生图备用路线 |
| `ark-official-verification.md` | 官方模型参数、人像输入及任务行为核实记录 |
| `validation-report.md` | 已验证事项及仍需实测的边界 |
| `firstframes-provenance.json`、`image-job-*.json`、`image-generation-jobs.json` | 图片来源、校验值及原始出图请求记录；不是视频平台操作提示词 |

原始图片生成请求中的参考路径用于追溯本机制作来源。运行视频API只需要包内首帧、视频提示词和manifest，不依赖这些原始参考路径。

脚本运行与接入排查由开发代理承担；当前你需要完成的是方舟账号登录、控制台试片和效果判断。
