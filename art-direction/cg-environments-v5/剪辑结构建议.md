# 开场 CG：加入环境镜头后的剪辑结构

建议保留七个人物事件，选用四张环境候选，成片仍为 **68秒**。环境镜头承担风灾的空间与后果，集中放在商行劳动之后、灾后写作之前。开场仍从母子关系进入，避免一开始就放暴风雨，让观众误以为童年失去母亲与后来的风灾发生在同一天。

下表环境编号暂按六张候选的生成顺序对应，实际采用以成图为准。

| 成片时间 | 镜头 | 观看内容 |
| --- | --- | --- |
| 00–05秒 | S01 照料 | 孩子放碗，母亲在床上。 |
| 05–10秒 | S02 空床 | 同机位，孩子将仍托在手中的碗和湿布一起放稳，母亲的位置空了。 |
| 10–17秒 | S03 商行 | 已长大的少年把账册安置到干处。 |
| 17–21秒 | E01 远海鸟瞰 | 雨墙逼近低岛，第一次看见生活所在的尺度。 |
| 21–26秒 | E03 门廊望街 | 回到地面，雨水遮住街巷，风压作用于屋檐。 |
| 26–33秒 | S04 抵窗 | 少年补上左掌，只承受一次风压。 |
| 33–37秒 | E04 风中码头 | 水撞上码头，缆绳受力，风灾越过他的房间。 |
| 37–42秒 | E05 灾后街巷 | 风雨已停，破损小屋与积水留下后果。 |
| 42–49秒 | S05 写作 | 右手完成一次收笔，停看已有文字。 |
| 49–59秒 | S06 支持 | 左手持信继续阅读，右手将已经在桌上的钱袋沿桌面推向旅行包。 |
| 59–68秒 | S07 登船 | 继续上梯，进船后留约两秒空画面。 |

新增环境共18秒，人物共50秒。缩短的是放碗、放稳碗布、安置账册后的重复等待；S06保留10秒，让阅读与把旅费推向旅行包的关系成立。钱袋从首帧就在桌上，不重新提起再放下，持信的左手不安排额外放纸动作。所有动作完成后至少留一点可感知的后果，不剪成连续动作演示。

E02低空海岸湾只作为E01的替代；E06甘蔗地或屋内外灾后细节只替代E05。六张不必全用。先确认它们的海岸、木屋、植被与人物场景相容；不要为了展示素材，反复从地面升空或跳到另一种灾害环境。

镜间以硬切为主。雨声在鸟瞰前稍早进入；从码头切灾后，猛烈水声迅速退去，让残余滴水建立时间变化，再由纸笔声引向写作。鸟瞰保持稳定视角，地面固定机位，靠雨、水、绳和人行动产生变化，不自动巡游风景。全片不加人声、对白或煽情配乐。

叙事链：**照料与失去 → 劳动 → 风暴逼近整个岛 → 人与环境承受 → 灾后书写 → 获得支持 → 离岛。**
