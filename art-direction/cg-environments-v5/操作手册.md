# 先看六张环境候选

打开 [环境首帧.html](环境首帧.html)。新增E01至E06已经分为鸟瞰、地面风暴、灾后三类；页面下方可展开与原人物镜头接在一起的68秒静态粗排。这是看构图与顺序的图片排列，尚不是视频预演。

| 镜号 | 画面 | 建议用途 |
|---|---|---|
| E01 | 远海雨墙与群岛鸟瞰 | 主选，建立风灾尺度 |
| E02 | 海湾与小港镇近岸鸟瞰 | 替换E01，强调居住地 |
| E03 | 门廊下观察斜雨街道 | 主选，回到人在地面能感到的距离 |
| E04 | 浪水、系缆柱与湿岸石 | 主选，把窗内受力延伸到港口 |
| E05 | 雨停后的破屋与清障街巷 | 主选，交代后果 |
| E06 | 倒伏甘蔗与泥水沟 | 替换E05，强调生计损失 |

这六张都是完成的候选，不必为了用完素材而全部生成视频。建议先选E01、E03、E04、E05，用18秒环境画面替换原版部分人物停顿，仍保持68秒。详见 [剪辑结构建议.md](剪辑结构建议.md)。这一顺序把风灾放在少年商行阶段之后，避免暗示母亲去世与风灾发生在同一天。

# 选定后的生成与剪辑

继续使用Seedance 2.5。每张环境原图位于 `firstframes/Exx.png`，对应动作提示词位于 `prompts/video/Exx.txt`。建议选中的镜头各生成12秒、16:9、720p、关闭音频。环境镜头的主要变化来自雨、水、植物与少量远处动作，E01只允许极慢的单向鸟瞰前移，其他机位固定。

图片确认后，API生产、下载、整理和剪辑准备由我执行。当前没有提交任何视频任务。原人物图复用在characters目录，仅供一起看；人物视频仍使用v4对应提示词，S02是碗布放稳、S06是把桌上的钱袋推向旅行袋。

本包保存了新图像提示词、六份视频动作提示词、六张2560×1440原始PNG、原七张人物图与费用记录。E03是原环境图经方舟pro局部编辑后的原始输出：只修正墙根物件，审图确认雨势与建筑保持。其余五张环境图为纯文字生成；交付文件均未再裁切、去标、压缩或重编码。

先看环境与人物如何相接 → 决定采用哪些环境镜头 → 再生成选中视频 → 按真实动作与天气变化剪辑。片内无对白、独白、AI配音或字幕；需要的环境声在后期单独处理。
