# 广场辩论：白天人物近景，第一版

本地真实组件 `src/ui/DebateActivity.ts` 已替换，三维主线自动使用同一组件。试玩页 `playtest.html` 直接导入正式组件，仅外围增加验证控件；不保存剧情进度。未发布线上，游戏版本保持 0.5.2。

## 拼接结构

1. `public/art/debate/daylight-v1/square.webp`：白天广场背景。
2. 现有 Hamilton v1 与保皇派 v2 主像素图集：复用正式提帧、朝向、口型与句后姿态。仅此辩论的听者采用较轻日光遮罩。
3. `crowd-balance.png`：透明群众与铜质表盘，指针独立由代码旋转。支持 0 / 50 / 100 对应右 60° / 中立 / 左 60°；这是群众支持，不将对方可信度混入。
4. `response-icons.svg`：自行绘制的四枚像素徽章；纸质回应卡、可切换语言的文字、节拍轨道与反馈均为真实 DOM。

背景、表盘使用内置 image_gen 生成，完整提示见 `prompts.json`，原件分别保留为 `square-source.png` 与 `crowd-balance-source.png`。原件经缩放与格式压缩后进入项目素材目录；人物仍使用正式 portraitPixels 提帧，不重新抠像。
